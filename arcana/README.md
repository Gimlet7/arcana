# 星隙 · ARCANA

暗紫与古金的沉浸式塔罗抽牌网页。原创的金线雕刻牌面，完整 78 张牌，含大阿卡那 22 张与四种花色各 14 张。

## 打开

直接双击同级输出中的 `星隙-ARCANA.html` 即可离线使用；也可以双击本目录的 `index.html`。不需要安装 Node.js、不需要密钥、不需要后端。建议使用支持 WebGL2 的现代 Chrome、Edge、Safari 或 Firefox。

若要部署，将本目录放到任何静态网站托管服务即可。请保留 `vendor/three.js` 与 `LICENSE.txt`。

## 使用

1. 选择 1、2、3、5、7 或 10 张牌，点击“开始”。
2. 镜头推进至圆木桌，点击已洗好的牌堆。
3. 从悬浮展开的 78 张牌中点选约定数量，或使用左右方向键与 Enter。触屏也可以使用下方的聚焦及选牌按钮。
4. 其余牌散为金色粒子，所选牌依次翻转并按正逆位落位。
5. 悬停或键盘聚焦可高亮卡牌并查看牌名；点击阅读牌意与牌位含义。
6. “解读”查看全阵，“复制”保留文字；“图鉴”搜索或筛选牌面。

右上角分别是舒缓动效与氛围音开关。默认静音；系统减少动态效果偏好自动生效。重新开始会重新洗牌。图形功能不可用时自动进入轻量场景。

## 视觉与实现

Three.js r170 渲染真实三维场景；包含程序木纹、雕刻牌位、烛火、软阴影、金色辉光、景深层次、浮尘与约五千颗消散粒子。镜头、扇形展开、悬浮选取及落牌均为连续动画。

所有牌面由 Canvas 2D 原创绘制，22 张大阿卡那有各自的象征构图；小阿卡那以四种花色、数字牌和宫廷牌构成统一的暗金线刻体系。木纹、音色及纹样也在设备上生成。网页运行时不请求远程图片、字体、音频或 API。

使用 `crypto.getRandomValues`、拒绝采样与 Fisher–Yates 洗牌；78 张牌不重复，每张牌正逆位独立等概率。抽牌不上传，不记录到服务器。

## 文件

`index.html` 为入口；`style.css` 为界面；`data.js` 是 78 张牌的正逆位文字及牌阵；`art.js` 是原创牌面与木纹；`scene.js` 是三维渲染与动画；`app.js` 负责交互、无障碍、图鉴、音频及解读复制。
